## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-list-mail-accounts`
- `allow-add-mail-account`
- `allow-remove-mail-account`
- `allow-recent-mail`
- `allow-mail-with`
- `allow-read-mail`
